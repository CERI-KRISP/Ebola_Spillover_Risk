# Ebola Spillover Risk Mapping

This repository contains the code used for the pre-print below:

**"Integrating ecological and anthropogenic risk identifies emerging Ebola spillover hotspots"** 

https://www.medrxiv.org/content/10.64898/2026.07.25.26358924v1

The analysis integrates ecological habitat suitability with key anthropogenic risk factors, after updating reservoir bats and orthoebolavirus environmental suitability models. 

## Repository structure

* `data/` — Input and output spatial and occurrence datasets for the spillover model
* `Bat_models/` — Data and codes for the Bat habitat suitability model
* `Ebola_models/` — Data and codes for the orthoebolavirus habitat suitability model
* `Figures/` — Final publication visualizations

## Key outputs

* Ecological habitat suitability maps for orthoebolavirus and putative bat reservoirs
* Anthropogenic spillover composite risk layers
* Temporal analysis of forest loss and built-up environment
* Continental-scale Ebola spillover-risk maps
